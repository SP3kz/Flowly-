# Flowly Extension

Flowly is an integrated buffer enhancer for your browser, acting like VSCode's integrated terminal for any text input. This version includes:

## Features
- Injected UI with Remix, Format, and Chat buttons
- OCR scanning for form and chat auto-fill
- Agentic tagging and formatting
- Vibe switcher (swipe gestures)
- WASM runtime kernel (Pyodide stub)
- Parses `conversations.json` into DAG workflows

## Install
1. Download ZIP
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Load Unpacked → Select this folder
